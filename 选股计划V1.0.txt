# A 股 AI 龙头盯盘系统 V1.1 总体定位

系统定位：

```text
AI 不负责无脑荐股；
AI 负责识别候选龙头、判断市场情绪、生成交易预案、盘中触发提醒、风控否决；
你负责人工确认和手动下单。
```

初期不建议自动下单。证监会对程序化交易的定义包括“通过计算机程序自动生成或者下达交易指令在证券交易所进行证券交易”的行为，所以 5 万本金阶段更适合做成“AI 预警 + 人工确认 + 手动下单”的纪律系统，而不是全自动交易机器人。([中国证券监督管理委员会][1])

系统核心目标：

```text
1. 只在市场情绪允许时交易；
2. 只做主线题材中的核心辨识度标的；
3. 只在盘中触发预案时交易；
4. 每一笔交易提前计算最大亏损；
5. 识别一字跌停闷杀和流动性失效；
6. 避免被 09:15-09:20 假竞价欺骗；
7. 避免被 09:30-09:33 的 VWAP 假破位误杀。
```

一句话：

> **这不是 AI 荐股器，而是“龙头战法的选股、盯盘、风控、执行纪律引擎”。**

# 一、系统总原则

## 1. 先判断能不能做，再判断买什么

系统每天第一步不是选股，而是判断：

```text
今天是否适合龙头战法？
```

如果市场情绪退潮，系统必须输出：

```text
今日禁止新开仓。
只处理持仓风险。
```

而不是硬找 3-5 只所谓“最强龙头”。

---

## 2. 盘后只生成候选，不生成买入结论

盘后 AI 只能说：

```text
XX 是候选龙头；
明天如果满足 A、B、C 条件，可以考虑交易；
如果触发 D、E、F 条件，直接放弃。
```

不能说：

```text
明天买 XX。
```

真正买不买，必须由次日盘中确认：

```text
09:24:30-09:25:00 最终竞价；
09:30-09:33 开盘呼吸窗口；
09:33-09:35 VWAP 稳定确认；
09:35-10:00 正式执行窗口。
```

---

## 3. 系统优先级

系统所有模块的优先级如下：

```text
交易规则正确性
> 流动性锁死风险
> 账户级风控
> 市场情绪状态
> 主线题材强度
> 个股龙头地位
> 竞价真实性
> VWAP 承接确认
> 买入触发
> 止盈止损
```

优先级解释：

```text
如果交易规则参数错误，不交易；
如果总龙头一字跌停闷杀，不交易；
如果账户亏损超限，不交易；
如果市场情绪退潮，不交易；
如果竞价是骗线，不交易；
如果 09:35 后 VWAP 承接失败，不交易。
```

## 2. 单笔仓位计算公式

每次不是想买多少就买多少，而是先算：

```text
错了最多亏多少钱？
```

公式：

```text
单笔最大亏损 = 账户权益 × 1%
止损距离 = (买入价 - 结构止损价) / 买入价
允许买入金额 = 单笔最大亏损 / 止损距离
```

示例：

```text
本金：50,000
单笔风险：500
买入价：10.00
结构止损价：9.50
止损距离：5%

允许买入金额 = 500 / 5% = 10,000 元
```

A 股买入申报数量通常应为 100 股或其整数倍，所以系统下单数量也要向下取整到 100 股整数倍。

伪代码：

```python
def calc_position(equity, entry_price, stop_price,
                  risk_pct=0.01, max_position_pct=0.25):
    risk_amount = equity * risk_pct
    stop_distance = (entry_price - stop_price) / entry_price

    if stop_distance <= 0:
        return 0

    # 止损距离超过 7%，说明买点太差，直接不买
    if stop_distance > 0.07:
        return 0

    raw_cash = risk_amount / stop_distance
    max_cash = equity * max_position_pct
    position_cash = min(raw_cash, max_cash)

    # A 股按 100 股整数倍买入
    shares = int(position_cash / entry_price / 100) * 100
    return shares
```

深交所 2026 年修订交易规则中，主板股票价格涨跌幅限制比例为 10%，创业板股票为 20%，并给出涨跌幅限制价格公式；上交所也发布 2026 年修订交易规则，明确自 2026 年 7 月 6 日起施行，同时其修订说明中提到主板风险警示股票涨跌幅限制比例由 5% 调整为 10%。

```python
limit_up = pre_close * 1.1

```

必须这样写：

```python
def get_price_limit(symbol, trade_date, pre_close, rule_registry):
    rule = rule_registry.lookup(symbol=symbol, trade_date=trade_date)

    if not rule.has_price_limit:
        return None, None

    limit_up = round_to_tick(
        pre_close * (1 + rule.price_limit_ratio),
        rule.tick_size
    )

    limit_down = round_to_tick(
        pre_close * (1 - rule.price_limit_ratio),
        rule.tick_size
    )

    return limit_up, limit_down
```

# 六、AuctionEngine：集合竞价真实性引擎

这是 V1.1 的第一个核心补丁。

A 股开盘集合竞价时间为 09:15-09:25；深交所规则明确，9:20-9:25 不接受参与竞价交易的撤销申报，其他接受申报时间内未成交申报可以撤销。

所以系统必须把集合竞价分成 4 个阶段。

---

## 阶段 1：09:15-09:20，可撤单诱导期

这个阶段：

```text
只观察，不定性。
```

用途：

```text
识别假强、骗线、诱多。
```

采集字段：

```text
early_auction_strength
early_max_bid_value
early_max_unmatched_bid
early_price_high
early_price_low
early_cancel_pressure
```

规则：

```text
09:15-09:20 的强势不能作为买入依据。
```

如果 09:16 很强，但 09:24:30 后明显转弱，系统标记：

```text
auction_fake_flag = True
```

---

## 阶段 2：09:20-09:24:30，不可撤单有效观察期

这个阶段开始具备参考价值，但仍然不是最终定性窗口。

## auction_strength 新定义

旧版：

```text
auction_strength = 高开幅度 + 竞价量能 + 未匹配买量
```

新版：

```text
auction_strength = final_auction_strength - fake_order_penalty
```

伪代码：

```python
def calc_auction_features(snapshots):
    early = snapshots.between("09:15:00", "09:20:00")
    valid = snapshots.between("09:20:00", "09:24:30")
    final = snapshots.between("09:24:30", "09:25:00")

    if final.empty:
        return {
            "auction_valid": False,
            "reason": "缺少 09:24:30-09:25:00 最终竞价数据"
        }

    early_strength = calc_strength(early)
    valid_strength = calc_strength(valid)
    final_strength = calc_strength(final)

    fake_order_ratio = (
        early_strength / final_strength
        if final_strength > 0 else float("inf")
    )

    fake_order_penalty = 0
    if fake_order_ratio > 3:
        fake_order_penalty += 20

    auction_strength = final_strength - fake_order_penalty

    return {
        "auction_valid": True,
        "early_strength": early_strength,
        "valid_strength": valid_strength,
        "final_strength": final_strength,
        "fake_order_ratio": fake_order_ratio,
        "auction_strength": auction_strength,
        "auction_fake_flag": fake_order_ratio > 3
    }
```

## 竞价超预期定义

一只票只有满足这些条件，才算竞价超预期：

```text
1. 09:24:30-09:25:00 最终高开幅度符合策略要求；

```

一句话：

```text
不是 09:16 强就叫强。
最后 30 秒还强，才是真的强。
```

# 七、VWAPEngine：VWAP 分时承接引擎

这是 V1.1 的第二个核心补丁。

原规则：

```text
跌破 VWAP 放弃；
站稳 VWAP 买入。
```

新版必须更精确：

```text
09:30-09:33 不因单次跌破 VWAP 判死刑；
09:33-09:35 开始稳定观察；
09:35 后 VWAP 才作为正式买卖纪律。
```

---

## VWAP 三阶段状态机

## 阶段 1：09:30-09:33，VWAP 初始化期

这个阶段：

```text
不使用单次跌破 VWAP 作为放弃依据。
```

因为龙头股开盘前三分钟经常剧烈换手，分时均价线容易被竞价量和开盘大单扭曲。

允许出现：

```text
短暂跌破 VWAP
围绕 VWAP 反复震荡
高开后快速洗盘
下杀后快速收回
```

但如果出现极端弱势，仍然可以直接放弃：

```text
1. 高开后快速杀到昨日收盘价下方；
2. 板块核心股集体跳水；
3. 同梯队高位股核按钮；
4. 个股放量长阴且没有承接；
5. 竞价最后 30 秒已经转弱，开盘继续确认弱。
```

---

## 阶段 2：09:33-09:35，VWAP 稳定确认期

这个阶段开始启用 VWAP，但不能机械。

有效跌破需要满足：

```text
1. 价格低于 VWAP；
2. 跌破幅度超过容忍阈值；
3. 持续时间足够；
4. 卖压确认；
5. 板块没有同步修复。
```

默认参数：

```text
vwap_break_tolerance = 0.3%-0.5%
vwap_break_confirm_seconds = 60 秒
```

输出状态：

```text
VWAP 偏强
VWAP 中性
VWAP 偏弱
```

---

## 阶段 3：09:35 之后，VWAP 正式生效期

09:35 后，VWAP 可以作为正式纪律。

对于 B 类容量龙：

```text
09:35 后持续跌破 VWAP 60-90 秒，放弃买入或减仓。
```

对于 C 类首板弱转强：

```text
09:35 后仍站不上 VWAP，弱转强失败。
```

对于 D 类人气龙反包：

```text
09:35 后仍在 VWAP 下方，反包评级下降。
```

对于 A 类空间板：

```text
VWAP 只是辅助。
核心看封板结构、炸板次数、回封速度、板块助攻。
```

---

## 双 VWAP 设计

系统建议同时计算两条 VWAP：

```text
session_vwap：
包含 09:25 集合竞价成交的全日 VWAP。

continuous_vwap：
只从 09:30 连续竞价开始计算的 VWAP。
```

用途：

```text
session_vwap：观察全日平均成本；
continuous_vwap：观察开盘后主动接力资金承接。
```

短线龙头早盘判断更应重视：

```text
continuous_vwap
```

因为集合竞价成交量可能非常大，会扭曲早盘均价。

## VWAP 有效破位定义

```python
def check_vwap_signal(current_time, price, vwap,
                      seconds_below_vwap,
                      sell_pressure_confirmed,
                      tolerance=0.004):
    if current_time < "09:33:00":
        return {
            "vwap_status": "INIT",
            "action": "观察，不因单次破 VWAP 放弃"
        }

    if "09:33:00" <= current_time < "09:35:00":
        if (
            price < vwap * (1 - tolerance)
            and seconds_below_vwap >= 60
            and sell_pressure_confirmed
        ):
            return {
                "vwap_status": "WEAK_CONFIRMING",
                "action": "降低评级，暂不买入"
            }

        return {
            "vwap_status": "STABILIZING",
            "action": "继续观察"
        }

    if current_time >= "09:35:00":
        if (
            price < vwap * (1 - tolerance)
            and seconds_below_vwap >= 90
            and sell_pressure_confirmed
        ):
            return {
                "vwap_status": "VALID_BREAK",
                "action": "放弃买入/按策略减仓"
            }

        if price > vwap:
            return {
                "vwap_status": "ABOVE_VWAP",
                "action": "承接有效"
            }

    return {
        "vwap_status": "NEUTRAL",
        "action": "无动作"
    }
```

# 九、市场情绪评分 MarketEmotionScore

满分 100 分。

```text
涨停家数：10分
跌停家数：10分
炸板率：10分
最高连板高度：10分
2进3晋级率：10分
3进4晋级率：10分
昨日涨停表现：10分
主线题材强度：15分
两市成交额：5分
核按钮/闷杀情况：10分
```

状态解释：

```text
EmotionScore >= 75：
强情绪，允许接力龙头。

60 <= EmotionScore < 75：
中强情绪，只做主线容量龙和核心龙头。

45 <= EmotionScore < 60：
弱情绪，只观察，不追高。

35 <= EmotionScore < 45：
退潮初期，禁止新开仓。

EmotionScore < 35：
强退潮，高位持仓主动减仓或清仓。
```

一票否决：

```text
市场总龙头一字跌停闷杀；
空间板集体断板；
昨日涨停指数大跌；
跌停家数暴增；
高位股连续核按钮。
```

# 十、Liquidity Lock Monitor：流动性锁死监控

这是风控最高层之一。

## 触发条件

```text
1. 股价等于跌停价；
2. 跌停卖一封单持续 3 分钟以上；
3. 跌停封单金额 / 20日平均成交额 > 30%；
4. 开盘成交额 / 跌停封单金额 < 5%；
5. 封单没有明显衰减。
```

## 状态

```text
LIQUIDITY_LOCKED
```

这意味着：

```text
止损信号已经触发，但无法成交；
风险不再是价格风险，而是流动性风险。
```

## 分级处理

```text
A级：市场总龙头 / 空间板 / 主线容量龙被闷杀
动作：全系统 DEFCON_1，当天禁止所有新开仓。

B级：板块核心龙头被闷杀
动作：该板块禁止新开仓，其他板块降低仓位。

C级：普通后排杂毛跌停
动作：只计入亏钱效应，不触发全局停机。
```

DEFCON_1 状态下：

```text
1. 禁止所有新开仓；
2. 禁止加仓；
3. 取消所有买入计划；
4. 只处理持仓卖出；
5. AI 不输出推荐，只输出风险报告。
```

# 十一、策略分型

# 十二、A 类：空间板 / 情绪总龙头模型

## 适用环境

```text
MarketEmotionScore >= 75
最高连板高度 >= 4板
主线题材清晰
高位股没有集体核按钮
昨日涨停溢价良好
空间板对板块有带动性
```

## 入池条件

```text
1. 全市场最高板或次高板；
2. 所属题材为主线或强分支；
3. 涨停时间靠前；
4. 板块内有 3 只以上涨停或大涨；
5. 分歧后能快速回封；
6. 没有基本面重大雷；
7. 不是纯庄股控盘；
8. 成交额足以正常进出。
```

## 竞价规则，V1.1 修正

A 类空间板对竞价极敏感，只看最终真实窗口：

```text
09:15-09:20 强：不作为买入依据；
09:24:30-09:25:00 强：才进入买入观察；
auction_fake_flag = True：取消接力计划。
```

如果出现：

```text
前面顶一字，最后 30 秒撤弱；
前面强高开，最后变成平开或低开；
同梯队核心股最后 30 秒跳水；
```

则：

```text
A 类接力取消。
```

## VWAP 规则，V1.1 修正

A 类空间板：

```text
不以 VWAP 为核心卖出依据。
```

原因：

```text
空间板的关键不是分时均价，而是封板结构、炸板次数、回封速度和板块助攻。
```

但如果：

```text
09:35 后持续在 VWAP 下方；
炸板不能回封；
板块后排集体跳水；
```

则说明空间板结构变弱。

## 买入触发

```text
1. 09:24:30-09:25:00 最终竞价强；
2. 没有竞价骗线；
3. 板块前排同步强；
4. 开盘没有系统性弱势；
5. 分歧后快速回封；
6. limit_break_count <= 2；
7. 回封时间 <= 3-5 分钟；
8. 封单质量较强；
9. 市场情绪没有退潮。
```

## 禁止买入

```text
1. 竞价最后 30 秒转弱；
2. auction_fake_flag = True；
3. 一字板开板后放巨量回封失败；
4. 同梯队高位股跌停；
5. 主线后排集体掉队；
6. 市场总龙头被核按钮；
7. 情绪分低于 65；
8. 炸板超过 2-3 次；
9. 止损距离超过 7%。
```

## 仓位

```text
普通空间板：5,000-8,000 元
A+ 市场总龙：8,000-10,000 元
极限不超过：12,000 元
```

## 止损

```text
1. 次日竞价明显弱于预期；
2. 低开超过 -4%，5分钟不能翻红；
3. 炸板后超过 5 分钟不能回封；
4. 爆量不能封板；
5. 同梯队核心股跌停；
6. 板块退潮；
7. 龙头地位丧失；
8. 持仓股跌停封死。
```

## 止盈

A 类不使用机械 R 倍数止盈。

```text
继续封板 + 板块助攻 + 情绪不退潮：持有；
首次爆量分歧但能回封：可卖 30% 机动仓；
炸板次数 >= 3：减仓或清仓；
炸板后 5 分钟不能回封：清仓；
断板且板块退潮：清仓；
爆量长上影：至少卖 70%；
龙头地位丧失：清仓。
```

核心原则：

```text
空间板不是涨多了卖，而是结构坏了卖。
```

# 十三、B 类：主线容量趋势龙模型

这是最适合你 5 万本金阶段优先练的模型。

## 适用环境

```text
MarketEmotionScore >= 60
主线题材清晰
成交额充足
趋势龙流动性好
不是极端一字连板
```

## 入池条件

```text
1. 所属题材是主线；
2. 板块成交额排名前 1-3；
3. 股价多头排列；
4. 放量突破平台或前高；
5. 板块内有涨停小弟助攻；
6. 基本面无明显雷；
7. 有机构或中线资金认可更好，但不作为买点。
```

## 竞价规则，V1.1 修正

B 类不要求极端强竞价，但要求稳定：

```text
1. 09:24:30-09:25:00 最后 30 秒稳定；
2. 高开 0%-5% 较好；
3. 最后 30 秒不能明显回落；
4. 板块前排不能低开；
5. auction_fake_flag = False。
```

如果：

```text
09:15 很强，09:25 转弱
```

则：

```text
不追开盘第一波，只等 09:35 后 VWAP 确认。
```

## VWAP 规则，V1.1 修正

B 类容量龙最依赖 VWAP：

```text
09:30-09:33：只观察，不因单次破 VWAP 放弃；
09:33-09:35：开始确认分时承接；
09:35 后：必须站稳 continuous_vwap，才允许买入。
```

有效买入要求：

```text
price > continuous_vwap
vwap_status = ABOVE_VWAP
seconds_above_vwap >= 60-90 秒
板块同步增强
成交额放大
```

## 买入触发

```text
1. final_auction_strength 符合预期；
2. auction_fake_flag = False；
3. 高开 0%-5%；
4. 09:35 后站稳 continuous_vwap；
5. 放量突破昨日高点或平台高点；
6. 板块指数同步向上；
7. 个股回踩 VWAP 不破后重新向上；
8. 止损距离 <= 7%。
```

## 禁止买入

```text
1. 高开超过 7% 后冲高回落；
2. 09:35 后持续跌破 VWAP；
3. 放量不涨；
4. 跌回平台内；
5. 板块只有它一个涨，缺乏扩散；
6. 市场情绪明显退潮；
7. auction_fake_flag = True。
```

## 仓位

```text
常规：10,000-12,500 元
强确认：12,500-15,000 元
极限不超过本金 30%
```

## 止损

```text
1. 跌回突破平台；
2. 09:35 后持续跌破 VWAP；
3. 跌破 VWAP 后 90 秒不能收回；
4. 收盘跌破 5 日线；
5. 买入后 2 个交易日不能创新高；
6. 板块主线退潮；
7. 跌破结构止损价。
```

## 止盈

B 类使用 R 倍数止盈：

```text
+1R：止损抬到成本；
+2R：卖出 1/3；
+3R：再卖出 1/3；
剩余仓位沿 5 日线、前日低点或趋势 VWAP 持有；
第一次爆量长上影：至少卖 50%；
跌破 5 日线：清仓。
```

# 十六、综合打分模型 DragonScore V1.1

最终每只股票生成一个 `DragonScore`。

```text
DragonScore =
市场情绪分 × 18%
+ 题材强度分 × 18%
+ 龙头地位分 × 22%
+ 量价动能分 × 12%
+ 竞价真实性分 × 10%
+ VWAP 承接分 × 8%
+ 资金结构分 × 5%
+ 基本面安全分 × 4%
+ 流动性安全分 × 3%
```

相比 V1.0，V1.1 增加：

```text
竞价真实性分
VWAP 承接分
```

## 交易评级

```text
DragonScore >= 85：
A+，核心候选，只在触发条件满足时交易。

75 <= DragonScore < 85：
A，重点观察，低仓试错。

65 <= DragonScore < 75：
B，只观察，不主动追高。

DragonScore < 65：
剔除。
```

# 十九、止盈止损总框架 V1.1

止损分 7 层：

```text
L0：交易规则错误止损
L1：流动性锁死止损
L2：账户级止损
L3：市场情绪止损
L4：竞价失败止损 / 放弃
L5：VWAP 承接失败止损 / 放弃
L6：个股结构止损
L7：时间止损与移动止盈
```

## L0：交易规则错误

如果无法确认：

```text
涨停价
跌停价
交易时间
交易规则版本
是否 ST
是否新股前五日
涨跌幅比例
```

则：

```text
禁止交易。
```

## L1：流动性锁死

触发：

```text
市场总龙头一字跌停封死；
空间板一字跌停封死；
持仓股一字跌停封死；
高位股集体核按钮。
```

动作：

```text
DEFCON_1；
禁止新开仓；
取消买入计划；
持仓优先处理卖出；
AI 不再输出推荐。
```

## L2：账户级止损

```text
单笔亏损达到 500 元：退出；
单日亏损达到 1,000 元：停止新开仓；
单周亏损达到 2,500 元：暂停交易；
月度回撤 8%-10%：停止实盘；
连续亏损 3 笔：暂停追高接力。
```

## L3：市场情绪止损

```text
MarketEmotionScore < 45：禁止新开仓；
MarketEmotionScore < 35：高位持仓主动减仓；
市场总龙头跌停：高位票清仓优先；
连板晋级率崩溃：停止接力。
```

## L4：竞价失败止损 / 放弃

```text
最后 30 秒竞价转弱；
auction_fake_flag = True；
未匹配卖量明显放大；
同题材前排竞价掉队；
昨日核心龙头核按钮。
```

动作：

```text
A类、C类直接取消；
B类、D类降级观察，必须等 09:35 后确认。
```

## L5：VWAP 承接失败止损 / 放弃

```text
09:33 前：不因单次破 VWAP 判死刑；
09:33-09:35：有效破位则降级；
09:35 后：持续破 VWAP 且卖压确认，放弃或减仓。
```

## L6：个股结构止损

```text
A类空间板：炸板不回封、断板、龙头地位丧失；
B类容量龙：跌回平台、跌破 5日线、跌破 VWAP；
C类首板：弱转强失败、回封失败；
D类反包：跌破首阴低点、跌破 10日线。
```

## L7：时间止损与移动止盈

```text
买入后 1 天没有强反馈：警惕；
买入后 2 天不能脱离成本区 3%：减仓或清仓；
买入后 3 天仍无新高：清仓。
```
